# styles/thedigitalstag

The custom animate "look" for thedigitalstag content. Built in Phase 2 from:

- `refs/gero-earn-vertical-upbeat.mp4` (the reference for color, tempo, cut rhythm)
- `brands/thedigitalstag/palette.json` (the stag blue palette)
- `brands/thedigitalstag/BRAND.md` (full brand spec)

When built, this folder will contain:

```
styles/thedigitalstag/
├── STYLE.md      drawing rules, palette tokens, motion habits, frame checklist
├── kit.js        the drawing + animation hooks called by the animate kit
├── sample.png    a representative frame
└── demo/         a complete demo piece that exercises the style
```

Until Phase 2, pieces can use any of the 7 built-in animate styles (cut-paper, crosshatch, riso, sketchbook, math, pixel, isometric) and apply the thedigitalstag palette via a wrapper.
